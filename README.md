# estudos-sql

Repositório criado para registrar meus estudos e minha evolução no aprendizado de SQL e Banco de Dados.

## 📚 Sobre

Neste repositório estão meus exercícios, consultas e práticas realizadas durante meus estudos de SQL.

O objetivo é desenvolver minha base em bancos de dados, melhorar meu raciocínio lógico e analítico e adquirir mais experiência prática com SQL.

## 🗂️ Conteúdos estudados

- Criação e manipulação de bancos de dados
- Criação de tabelas
- `SELECT`
- `INSERT`
- `UPDATE`
- `DELETE`
- `WHERE`
- `ORDER BY`
- `GROUP BY`
- `HAVING`
- Funções de agregação
- `JOIN`
- Chaves primárias e estrangeiras
- `AUTO_INCREMENT`
- `FOREIGN KEY`
- Usuários e permissões
- Entre outros conceitos de Banco de Dados

## 🛠️ Tecnologias

- MySQL
- SQL
- PopSQL

## 🎯 Objetivo

Continuar aprimorando meus conhecimentos em Banco de Dados, SQL e análise de dados, aplicando os conhecimentos adquiridos em estudos, cursos e projetos práticos.
